## 2. DEVICE DRIVERS (Cốt lõi)

### 2.1 Character Device Drivers
```c
// Framework cơ bản cần hiểu
static const struct file_operations fops = {
    .owner = THIS_MODULE,
    .open = device_open,
    .release = device_release,
    .read = device_read,
    .write = device_write,
    .unlocked_ioctl = device_ioctl,
};
```

**Ứng dụng:** UART, GPIO, sensors, custom protocols

### 2.2 Platform Drivers (Quan trọng nhất)
```c
// Structure cần nắm vững
struct platform_driver {
    int (*probe)(struct platform_device *);
    int (*remove)(struct platform_device *);
    struct device_driver driver;
};
```

**Ứng dụng:** SoC peripherals, memory-mapped devices

### 2.3 I2C/SPI Drivers
```c
// I2C driver structure
static struct i2c_driver my_driver = {
    .driver = {
        .name = "my-i2c-device",
        .of_match_table = my_of_match,
    },
    .probe = my_probe,
    .remove = my_remove,
};
```

**Ứng dụng:** Sensors, EEPROMs, RTCs, ADCs

### 2.4 Network Device Drivers
- **net_device structure**
- **Socket buffers (sk_buff)**
- **NAPI (New API) polling**

**Ứng dụng:** Ethernet, WiFi, custom network protocols

## 3. DEVICE TREE (Bắt buộc cho ARM)

### 3.1 Device Tree Syntax
```dts
// Ví dụ cần hiểu
my_device: device@12340000 {
    compatible = "vendor,my-device-v1.0";
    reg = <0x12340000 0x1000>;
    interrupts = <0 25 IRQ_TYPE_LEVEL_HIGH>;
    clocks = <&clk_gate 0>;
    pinctrl-names = "default";
    pinctrl-0 = <&device_pins>;
    status = "okay";
};
```

### 3.2 Device Tree APIs
```c
// APIs cần nắm vững

```

## 4. INTERRUPT HANDLING (Quan trọng)

### 4.1 Interrupt Request và Handling
```c
// Hard IRQ handler
irqreturn_t my_irq_handler(int irq, void *dev_id)
{
    // Minimal processing
    // Schedule tasklet/workqueue if needed
    return IRQ_HANDLED;
}

// Threaded IRQ (recommended cho embedded)
irqreturn_t my_threaded_irq(int irq, void *dev_id)
{
    // Can sleep, do heavy processing
    return IRQ_HANDLED;
}
```

### 4.2 Bottom Half Processing
- **Tasklets** (atomic context)
- **Workqueues** (process context)
- **Threaded interrupts**
